# AS5600 — Driver Reference Summary

> Datasheet: ams, v1-06, 2018-Jun-20  
> Применение: датчик угла ротора для управления PMSM-двигателем

---

## 1. Общая информация

| Параметр | Значение |
|---|---|
| Тип | 12-bit бесконтактный магнитный датчик угла (Hall-based) |
| Принцип | Диаметрально намагниченный магнит на оси, компонента Bz |
| Разрешение | **12 бит → 4096 отсчётов / 360°** |
| Погрешность (INL) | ±1° при 360° диапазоне |
| Пакет | SOIC-8 |
| Питание | 3.3V или 5.0V |
| Температура | −40 … +125 °C |

> **Важно для FOC/PMSM:** датчик даёт абсолютный угол без интегрирования — нет накопления ошибки.  
> DIR=GND → значение растёт по часовой стрелке. DIR=VDD → против часовой.

---

## 2. Интерфейсы и выходные сигналы

### 2.1 I²C (основной интерфейс для драйвера)

| Параметр | Значение |
|---|---|
| Режимы | Standard (100 kHz), Fast (400 kHz), **Fast-mode Plus (1 MHz)** |
| Макс. частота SCL | **1 MHz** |
| 7-bit адрес | **0x36** (фиксированный, только один датчик на шине) |
| Тип | Slave only (master — MCU) |
| Стрейчинг | **Не поддерживается** (Clock Stretching absent) |
| Передача | MSB first |
| Фильтр на входах | подавляет спайки < 50 ns |

#### I²C Timing (Fast-mode Plus, актуально для 1 MHz)

| Символ | Параметр | Min | Max | Ед. |
|---|---|---|---|---|
| fSCLK | Частота SCL | — | **1.0 MHz** | MHz |
| tBUF | Время между STOP и START | 0.5 | — | μs |
| tHD;STA | Hold time START | 0.26 | — | μs |
| tLOW | Низкий уровень SCL | 0.5 | — | μs |
| tHIGH | Высокий уровень SCL | 0.26 | — | μs |
| tSU;STA | Setup Repeated START | 0.26 | — | μs |
| tHD;DAT | Data hold time | — | 0.45 | μs |
| tSU;DAT | Data setup time | 50 | — | ns |
| tR | Фронт нарастания SDA/SCL | — | 120 ns | ns |
| tF | Фронт спада SDA/SCL | — | 120 ns | ns |
| tSU;STO | Setup STOP | 0.26 | — | μs |

> Шина open-drain; подтягивающие резисторы выбираются под ёмкость линии ≤ 550 pF.

### 2.2 Аналоговый выход (OUT pin)

- **0–100% VDD** (OUTS = 00) или **10–90% VDD** (OUTS = 01, режим потенциометра)  
- Нагрузка: ≥ 100 kΩ (full-range), ≥ 10 kΩ (reduced-range)  
- Не подходит для высокоскоростного управления двигателем.

### 2.3 PWM-выход (OUT pin)

| PWMF[1:0] | Частота |
|---|---|
| 00 | 115 Hz |
| 01 | 230 Hz |
| 10 | 460 Hz |
| 11 | **920 Hz** |

> 920 Hz PWM → период 1.09 ms → слишком медленно для FOC с несколькими кГц ШИМ.  
> **Вывод: для двигателя использовать только I²C.**

## 3. Map регистров

| Адрес | Имя | R/W | Описание |
|---|---|---|---|
| 0x00 | ZMCO | R | Число записей ZPOS/MPOS в OTP (0–3) |
| 0x01–0x02 | ZPOS[11:0] | R/W/P | Нулевая позиция (стартовый угол) |
| 0x03–0x04 | MPOS[11:0] | R/W/P | Максимальная позиция (конечный угол) |
| 0x05–0x06 | MANG[11:0] | R/W/P | Максимальный угол диапазона |
| 0x07–0x08 | CONF[13:0] | R/W/P | Конфигурация (см. ниже) |
| 0x0B | STATUS | R | Состояние датчика (MH, ML, MD) |
| **0x0C–0x0D** | **RAW ANGLE[11:0]** | **R** | **Сырой угол, без масштабирования** |
| **0x0E–0x0F** | **ANGLE[11:0]** | **R** | **Масштабированный угол (с гистерезисом 10 LSB)** |
| 0x1A | AGC | R | Автоматическое усиление (0–255 / 0–128) |
| 0x1B–0x1C | MAGNITUDE[11:0] | R | Величина вектора (CORDIC magnitude) |
| 0xFF | BURN | W | Команды записи OTP (0x80 / 0x40) |

> Для FOC читаем **RAW ANGLE (0x0C–0x0D)** — без гистерезиса ±10 LSB по краям диапазона.

## 4. Регистр CONF (0x07–0x08)

| Биты | Имя | Значения |
|---|---|---|
| [1:0] | PM — Power Mode | `00`=NOM, `01`=LPM1, `10`=LPM2, `11`=LPM3 |
| [3:2] | HYST — Hysteresis | `00`=OFF, `01`=1 LSB, `10`=2 LSB, `11`=3 LSB |
| [5:4] | OUTS — Output Stage | `00`=аналог 0–100%, `01`=аналог 10–90%, `10`=PWM |
| [7:6] | PWMF — PWM Freq | `00`=115 Hz, `01`=230 Hz, `10`=460 Hz, `11`=920 Hz |
| [9:8] | SF — Slow Filter | `00`=16x\*, `01`=8x, `10`=4x, `11`=**2x** |
| [12:10] | FTH — Fast Filter Threshold | см. таблицу ниже |
| [13] | WD — Watchdog | `0`=OFF, `1`=ON (→ LPM3 через 1 мин без движения) |

\* SF=00 (16x) принудительно устанавливается в LPM режимах.

### Медленный фильтр (SF)

| SF | Задержка ступеньки | Шум RMS (1σ) |
|---|---|---|
| 00 (16x) | **2.2 ms** | 0.015° |
| 01 (8x) | 1.1 ms | 0.021° |
| 10 (4x) | 0.55 ms | 0.030° |
| 11 (2x) | **0.286 ms** | 0.043° |

### Быстрый фильтр (FTH)

| FTH | Порог перехода slow→fast | Порог fast→slow |
|---|---|---|
| 000 | Только медленный фильтр | — |
| 001 | 6 LSB | 1 LSB |
| 010 | 7 LSB | 1 LSB |
| 011 | 9 LSB | 1 LSB |
| 100 | 18 LSB | 2 LSB |
| 101 | 21 LSB | 2 LSB |
| 110 | 24 LSB | 2 LSB |
| 111 | 10 LSB | 4 LSB |

> **Быстрый фильтр:** активируется, когда изменение угла превышает порог FTH.  
> После скачка укладывается в 2 периода дискретизации. После — возвращается к медленному.

## 5. Частота дискретизации и время отклика

| Параметр | Значение |
|---|---|
| Внутренняя частота дискретизации (F_S) | **150 μs** (≈ 6.7 kHz) |
| Время включения (power-up) | 10 ms |
| Время отклика при SF=11, fast filter ON | **~0.286 ms** (одна ступенька) |
| Время отклика при SF=11, fast filter OFF | 0.286 ms |
| Время отклика при SF=00 (по умолчанию) | 2.2 ms |

> **Вывод для FOC:** внутренний цикл обновления угла — 150 μs (~6.7 кГц). При SF=11 и FTH≠000 задержка фильтра — около 2× 150 μs = 300 μs. При I²C 1 MHz чтение 2 байт занимает ~25 μs, что вполне вписывается в цикл ШИМ 4–8 kHz.

## 6. Режимы энергопотребления

| Режим | PM[1:0] | Ток (typ) | Период опроса датчика |
|---|---|---|---|
| **NOM** | `00` | **6.5 mA** | **непрерывно** |
| LPM1 | `01` | 3.4 mA | 5 ms |
| LPM2 | `10` | 1.8 mA | 20 ms |
| LPM3 | `11` | 1.5 mA | 100 ms |

> В LPM1–LPM3 медленный фильтр принудительно SF=00 (16x, задержка 2.2 ms).  
> **Для FOC всегда PM=00 (NOM), Watchdog OFF.**

## 7. Регистр STATUS (0x0B)

| Бит | Имя | Значение = 1 |
|---|---|---|
| 5 | MH | AGC на минимуме → магнит **слишком близко / сильный** |
| 4 | ML | AGC на максимуме → магнит **слишком далеко / слабый** |
| 3 | MD | Магнит **обнаружен** (норма) |

> Инициализация: проверить `MD == 1` перед стартом управления.  
> MH и ML — диагностика: оптимальное поле 30–90 mT (ось Z на поверхности чипа).  
> AGC (0x1A) должен быть ~128 (5V) или ~64 (3.3V), если магнит установлен правильно.

## 8. Конфигурация для максимальной скорости (FOC)

### Рекомендуемые настройки CONF для управления двигателем

```
CONF[13:0] = 0b00_001_11_00_00_00
                  ^^^FTH  ^^ SF  ^^ PM
```

В шестнадцатеричном:

| Поле | Значение | Биты |
|---|---|---|
| PM = NOM | `00` | [1:0] |
| HYST = OFF | `00` | [3:2] |
| OUTS = аналог (или не важно при I²C) | `00` | [5:4] |
| PWMF | `00` | [7:6] |
| SF = 2x | `11` | [9:8] |
| FTH = 6 LSB | `001` | [12:10] |
| WD = OFF | `0` | [13] |

Итого: `CONF = 0x0300 | (0b001 << 10) | (0b11 << 8) = 0x0700`

```
// CONF register value for max speed, no watchdog, fast filter on
// PM=NOM, HYST=OFF, SF=2x, FTH=6LSB, WD=OFF
#define AS5600_CONF_MOTOR  0x0700U
```

> Это значение записывается в RAM (не в OTP). Утилизируется после power-cycle:
> нужно переписывать CONF при каждом включении, если не записано в OTP.

## 9. I²C Protocol — последовательности чтения

### Чтение угла (2 байта, основная операция)

```
START
> 0x6C (0x36 << 1 | WRITE)   ACK
> 0x0C                        ACK   ← адрес регистра RAW ANGLE HIGH
REPEATED START
> 0x6D (0x36 << 1 | READ)    ACK
< DATA_HIGH                   ACK   ← RAW ANGLE[11:8]
< DATA_LOW                    NACK  ← RAW ANGLE[7:0]
STOP

angle = ((DATA_HIGH & 0x0F) << 8) | DATA_LOW;  // 12-bit, 0..4095
```

Или для ANGLE (с гистерезисом):

```
адрес регистра = 0x0E
```

### Чтение STATUS + AGC + MAGNITUDE + ANGLE за один burst

Автоинкремент адреса поддерживается. Читаем 7 байт от 0x0B:

```
START → write 0x36 → addr 0x0B → RS → read 0x36 →
[STATUS][RAW_HI][RAW_LO][ANG_HI][ANG_LO][AGC][MAG_HI]...[NACK][STOP]
```

### Запись CONF (при каждом старте)

```
START
> 0x6C   ACK
> 0x07   ACK   ← адрес CONF HIGH byte
> 0x07   ACK   ← CONF[13:8] = 0x07 (SF=11, FTH=001)
> 0x00   ACK   ← CONF[7:0]  = 0x00 (PM=NOM, HYST=OFF, OUTS=00, PWMF=00)
STOP
```

## 10. Запись в OTP (только если нужна постоянная конфигурация)

> **Внимание:** OTP — однократная запись. BURN_ANGLE — max 3 раза. BURN_SETTING — только 1 раз.

### Сохранить CONF и MANG (Option C)

1. Записать `MANG` и `CONF` через I²C в RAM
2. Записать `0x40` в регистр `0xFF` → BURN_SETTING
3. Подождать ≥ 1 ms
4. Верификация: записать `0x01`, `0x11`, `0x10` в `0xFF` → загрузка OTP в RAM
5. Читать CONF и MANG — сверить

### Сохранить ZPOS/MPOS (Option A)

1. Повернуть магнит в нулевую позицию
2. Прочитать `RAW ANGLE` → записать в `ZPOS`
3. Повернуть магнит в конечную позицию (> 18°)
4. Прочитать `RAW ANGLE` → записать в `MPOS`
5. Записать `0x80` в `0xFF` → BURN_ANGLE
6. Верификация — аналогично

> Для PMSM в полном диапазоне 360° — ZPOS/MPOS программировать **не нужно** (использовать полный диапазон).

## 11. Чтение угла в STM32 — алгоритм инициализации

```c
// 1. Power-up wait
vTaskDelay(pdMS_TO_TICKS(10));

// 2. Check magnet
STATUS = I2C_ReadByte(0x36, 0x0B);
if (!(STATUS & 0x20)) { PANIC(); }  // MD bit = bit5

// 3. Set CONF for max performance (RAM only, re-applied on each boot)
// CONF[14:8] = 0x07 (SF=11, FTH=001), CONF[7:0] = 0x00
I2C_WriteBytes(0x36, 0x07, {0x07, 0x00});
vTaskDelay(pdMS_TO_TICKS(1));

// 4. Normal operation: read RAW ANGLE at I2C 1MHz
uint16_t rawAngle = I2C_ReadWord(0x36, 0x0C);  // [11:0] = 0..4095
float angleDeg = rawAngle * (360.0f / 4096.0f);
```

## 12. Ключевые ограничения и особенности

- **Только один адрес 0x36** — невозможно подключить два AS5600 на одну I²C шину без мультиплексора.
- **Нет clock stretching** — мастер должен выдерживать минимальные тайминги.
- Если `MD == 0` (нет магнита) → выход OUT принудительно драйвится в 0, I²C продолжает работать.
- **ANGLE** имеет гистерезис 10 LSB вблизи 0°/360° — для FOC использовать **RAW ANGLE**.
- При LPM режимах SF принудительно = 16x — не использовать LPM при управлении двигателем.
- Магнит должен быть диаметрально намагничен, ориентация по оси Z к чипу, `Bz = 30–90 mT`.
- AGC работает автоматически — компенсирует температуру и изменение зазора.
